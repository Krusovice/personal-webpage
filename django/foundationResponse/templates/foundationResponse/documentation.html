Foundation Response Predictor - Documentation

Linear Regression Model

Applied Dataset

The dataset has been created by +5000 simple FE models carried out by Plaxis 2D and generated by the software's Python API.

The models have been generated within a range of parameters and simplifications listed below.

  • Foundation is modelled as a stiff plate element with a width between 1-4 m lying in terrain level.
  • Load is defined as a lineload equivalent to 100 kPa times foundation width. The lineload is located with a random eccentricity, up to 0.3 foundation width, from foundation center.
  • Boundary conditions are defined as normally fixed. Bottom BCs are located 2 times foundation width from terrain and the model is 4 times foundation width wide, with the foundation placed centrally in the model.
  • Subgrades are created in layers of 0.5 m from terrain to bottom BCs. The soil is modelled with a Mohr Coulomb stress and failure criterion. Each layer has been modelled with a random E-modulus between 10 and 100 MPa. Poissons ratio is set to 0.3. An angle of friction of 40° are applied. A cohesion of 300 kPa are applied. Hence, the soils are not expected to yield, but tension cutoff is applied.

Model Features

In its current state, the model takes in following inputs.

  • Foundation width
  • Load Eccentricity
  • Soil layers' E-modulus

The load is set to 100 kPa, and therefore dependent on the foundation width. The strength parameters for the soil materials have been predefined in its current state.

The simplified features are applied as the model is currently in an early stage, and additional features such as variable load and soil strength parameters will be implemented in future model revisions.

Feature Engineering

Inversed Subgrade E-modulus

The settlements to E-modulus are an inverse linear correlation; with an increased E-modulus, the settlements are expected to decrease, whereas with an increased E-modulus, the settlements are expected to go towards infinity.

Therefore, applying the inverse E-modulus instead of the E-modulus as features to the calculations, the linear regression model is expected to capture the inverse-linear behavior of the settlement to E-modulus correlation.

Subgrade depth to foundation width ratio

For smaller foundation widths, the upper layers become significantly more important compared to the deeper layers, as the stress propagation spreads out causing almost no strain in the deeper layers. The increment of this effect decreases per foundation width, as the foundation size increases. Hence, the difference between a 1-2 m foundation width is significantly larger than a 4-5 m foundation width. When the linear regression model fits to all model results and they are weighted evenly, it is evident, that feature coefficient for the deeper layers are overestimated for small foundations, and that the upper layers are significantly underestimated for smaller foundations.

The effect can to some degree be captured in the linear regression model by adding a new feature per soil layer, which is the soil layers' inverse stiffness multiplied by foundation size. This provides a parameter that allows the foundation size' influence on the soil layer (to a first degree) to be captured. That feature coefficient per soil layer along with the soil layer coefficient itself, allows for a non-linear soil layer influence in relation to foundation size, and allow a larger foundation to weigh the deeper soil layer coefficients higher.

Model Performance

The dataset was split into 90% training and 10% testing.

Below is shown the models predicted settlement values compared to actual settlement values. The linear regression model overestimates by up to 10 % and underestimates by up to 6 % compared to the actual FE results. The 2nd order polynomial regression model overestimates by up to 4 % and underestimates by down to 3 % compared to the actual FE results.

  • R²: 0.9984
  • Mean Absolute Percent Error: 0.0150
  • RMSE / Mean: -0.0186
